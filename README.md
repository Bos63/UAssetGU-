# UAssetGU - APK Build

Bu depo artık temel bir Android uygulama iskeleti içerir ve APK üretimi için hazırdır.

## Gereksinimler
- Android SDK (API 34)
- JDK 17
- Gradle 8.x

## APK alma
Aşağıdaki komutla debug APK üretebilirsiniz:

```bash
gradle :app:assembleDebug
```

Üretilen dosya:

`app/build/outputs/apk/debug/app-debug.apk`
